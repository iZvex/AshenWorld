# Правила разработки ASHEN WORLD

## Язык

Все сообщения коммитов, комментарии в коде, названия заданий автоматической сборки, сообщения в логах и техническая документация пишутся **только на русском языке**.

Исключение составляют технические идентификаторы, которые требует синтаксис: имена файлов (`project.godot`, `ci.yml`), ключи настроек, названия команд (`--export-debug`), имена классов и переменных, а также общеупотребительные названия технологий (`Godot`, `GDScript`, `Android`, `APK`, `JSON`, `YAML`).

Соблюдение правила для коммитов проверяется автоматически: `tools/validate_repo.py` убеждается, что в сообщении последнего коммита есть кириллица.

## Проверки перед отправкой

```bash
python3 tools/validate_repo.py                       # структура, данные, скрипты, настройки, язык коммита
/home/user/tools/actionlint .github/workflows/ci.yml  # описание сборки
godot --headless --path . --editor --quit             # импорт и разбор скриптов
godot --headless --path . --quit-after 120            # пробный запуск главной сцены
```

Отправка в `main` автоматически запускает сборку. Управление ей — через `/home/user/tools/gh_ops.py`: `push`, `dispatch`, `runs`, `wait`, `status`, `logs`, `artifacts`.

## Сборка Android APK

- Пресет `Android` описан в `export_presets.cfg`: сборка без Gradle на готовых шаблонах Godot 4.7.2.
- Имя пакета `com.izvex.ashenworld`, название `ASHEN WORLD`, версия `0.1.0` (код `1`).
- Портретная ориентация задаётся настройкой `display/window/handheld/orientation=1` в `project.godot`; сжатие `ETC2/ASTC` включено обязательно для Android.
- Разрешение на доступ к интернету не запрашивается: MVP полностью офлайн.
- Ключи подписи в репозиторий не попадают: в CI создаётся временный отладочный ключ, путь к нему передаётся через настройки редактора.
- Проверки сборки: размер APK больше 1 МБ, подпись через `apksigner`, имя пакета и название приложения через `aapt`, выгрузка артефакта `AshenWorld-debug-apk` со сроком хранения 14 дней.
- Шаблоны экспорта и исполняемый файл Godot кэшируются, поэтому повторные сборки проходят быстрее.

## Структура данных

Все вероятности, цены и коэффициенты баланса хранятся централизованно в `data/balance.json` и читаются через автозагрузку `GameConfig`. Дублировать формулы и правила в разных скриптах запрещено.
