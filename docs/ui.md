# Оформление интерфейса

## Стиль

Тёмное фэнтези: почти чёрный фон с фиолетовым градиентом, силуэты разрушенных арок, пепел и тлеющие угли. Акценты — угольный оранжевый, блёклое золото и рунная лаванда. Все графические материалы оригинальные и нарисованы вручную в SVG.

| Цвет | Значение | Назначение |
|---|---|---|
| `#0B0910` | почти чёрный | основа фона |
| `#17121F` | тёмная слива | карточки и панели |
| `#4A3A58` | приглушённый фиолет | рамки |
| `#E08A3C` | уголь | рамка кнопки, угли, символ |
| `#F4C98A` | золото | заголовок, всплывающий урон по врагу |
| `#B49AC6` | рунная лаванда | щит, второстепенные акценты |
| `#E6DCCB` | пергамент | основной текст |
| `#9A8CA3` | приглушённый | подписи |
| `#A63D40` | багровый | здоровье врага, урон по герою |
| `#6E8CA8` | стальной | здоровье героя |

Палитра и все стили собраны в `scripts/ui/ashen_style.gd`: узлы сцены не дублируют цвета и скругления.

## Композиция сцены

Портретная ориентация, отступы 32/48, интерфейс рассчитан на управление одной рукой.

- Заголовок `ASHEN WORLD`, разделитель, подпись «ПЕПЕЛ · РУИНЫ · АВТОМАТИЧЕСКИЙ БОЙ».
- Карточка противника: имя и багровая полоса здоровья.
- Центральный символ и `CPUParticles2D` с поднимающимися углями.
- Карточка героя: имя, стальная полоса здоровья, отдельная тонкая полоса щита.
- Крупная кнопка навыка высотой не менее 96 пикселей; во время отката блокируется и показывает оставшиеся секунды.
- Панель лога боя с переносом строк и семью последними событиями.
- Строка состояния с числом разделов баланса.

При попадании карточка цели на мгновение вспыхивает, над ней появляется всплывающее число урона, которое поднимается и растворяется. Всё это работает от реальных сигналов `CombatSystem`, декоративных заглушек нет.

| Создание сцены | Тема применена, стили кнопки и карточки доступны |

## Запуск проверки

```bash
godot --headless --path . --editor --quit          # импорт SVG и разбор скриптов
godot --headless --path . --script tests/test_ui.gd
godot --headless --path . --quit-after 120         # быстрый запуск сцены
```

По договорённости проверяется только добавленное оформление. Полная сборка APK запускается отдельно, когда нужен пакет для телефона: `python3 /home/user/tools/gh_ops.py dispatch`.
